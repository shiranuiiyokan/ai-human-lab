AI人物研究 Automation（以下「本アプリ」）は、YouTube チャンネル「AI人物研究」の動画制作・投稿自動化を目的として運用されます。

取得・利用する Google ユーザーデータ

本アプリは YouTube Data API を利用し、認証したユーザーの YouTube チャンネル識別情報の確認、および動画アップロードに必要な範囲のデータへアクセスします。

要求する主な OAuth スコープは youtube.upload と youtube.readonly です。

利用目的

取得したデータは、誤った YouTube チャンネルへの投稿防止、動画の非公開・予約・公開アップロード等、本アプリの自動投稿機能の提供にのみ使用します。

保存

OAuth のクライアント情報およびリフレッシュトークンは、GitHub Repository Secrets 等の非公開の資格情報ストアに保存します。トークンを公開リポジトリへ直接保存しません。

第三者提供・販売

Google ユーザーデータを第三者へ販売しません。また、本アプリの機能提供に必要な場合を除き、第三者へ共有しません。

Google API Services User Data Policy

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

削除・アクセス取消

ユーザーは Google アカウントのセキュリティ設定から本アプリのアクセス権を取り消せます。保存済みの資格情報は、運用者が GitHub Secrets 等から削除できます。
