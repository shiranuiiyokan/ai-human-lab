AI人物研究 Automation

AI人物研究 Automation は、YouTube チャンネル「AI人物研究」の動画制作・投稿を自動化するための個人運用ツールです。

このアプリは、ユーザー本人が認証した YouTube アカウントに対して、動画のアップロードと、誤投稿防止のためのチャンネル識別確認を行います。

Google データの利用目的

YouTube Data API を使用し、動画アップロード（youtube.upload）と、認証中のチャンネル確認（youtube.readonly）に必要な範囲でデータへアクセスします。

Google Drive への自動処理は別のサービスアカウントで行い、この OAuth アプリで一般ユーザーの Google Drive データへアクセスしません。
