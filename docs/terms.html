利用規約

最終更新日: 2026-10-02

AI人物研究 Automation は、YouTube チャンネル「AI人物研究」の動画制作・投稿を自動化する個人運用ツールです。

本アプリは、認証したユーザー本人の指示・設定に基づいて YouTube Data API を利用します。第三者のアカウントへ無断でアクセスする目的では使用しません。

Google、YouTube、GitHub 等の外部サービスの利用には、それぞれの利用規約・ポリシーが適用されます。

外部サービスの仕様変更、障害、API 制限等により、本アプリの全部または一部が利用できない場合があります。
